# AGENTS.md

Инструкции для AI-агентов, работающих над этим репозиторием.

## О проекте

Браузерная игра «три в ряд» (match-3) для ПК и мобильных устройств.
Игрок меняет местами две соседние фишки; линия из 3+ фишек одного цвета объединяется
в ячейку уровнем выше, сверху падают новые, возможны каскады.

Главная особенность — **система объединения ячеек**: каждое совпадение превращает фишки
в ячейки более высокого уровня, которые приносят намного больше очков.

## Стек

- **TypeScript** (strict)
- **Phaser 3** — движок (сцены, твины, ввод, звук)
- **Vite** — сборка и dev-сервер
- **Vitest** — тесты
- **ESLint + Prettier**
- npm

## Команды

```bash
npm install
npm run dev        # dev-сервер, здесь же доступен редактор уровней
npm run build      # сборка в dist/
npm run test       # Vitest
npm run lint
npm run typecheck  # tsc --noEmit
npm run simulate   # бот играет партии и считает очки: [-- <партий> <ходов> [цены] [режимы]]
```

Задача считается выполненной, только когда проходят `test`, `lint` и `typecheck`.

## Режим игры

- Игра состоит из **уровней с целями**.
- **Ограничение по ходам** задаётся уровнем, когда оно нужно (у уровня может не быть лимита).
- Размер поля, набор цветов, форма поля и препятствия задаются **в описании уровня**.

## Правила игры

### Базовые

- Обмен — только с соседней по стороне клеткой. Обмен без совпадения откатывается и не тратит ход.
- Совпадение — 3+ фишки одного цвета **и одного уровня** по горизонтали или вертикали,
  а для 1 уровня ещё и квадрат 2×2. Фигуры с общими клетками сливаются в одну группу.
- Как определяется фигура группы 1 уровня:
  - есть квадрат 2×2 → **квадрат** (важнее любой другой фигуры);
  - одна линия: 3 → 3 в ряд, 4 → 4 в ряд, 5 и больше → **как 5 в ряд**;
  - пересекающиеся линии: ровно 5 фишек → **L/T**, больше (длинный луч) → **как 5 в ряд**.
- Группа ячеек 2–3 уровня считается по числу ячеек любой формы; 6 и больше → **как 5**.
  Квадрат 2×2 для них совпадением не является.
- После удаления: гравитация вниз → заполнение сверху → снова поиск совпадений (каскад).
  Фишки **пролетают сквозь дыры** в поле. Новые фишки — 1 уровня, случайного цвета,
  совпадения среди них допускаются (из них и получаются каскады).
- Стартовое поле — без готовых совпадений и хотя бы с одним возможным ходом.
- Если ходов нет — перемешать поле:
  - «ходов нет» — нет обмена двух обычных фишек, дающего совпадение (спецфишки ходом
    не считаются); проверка — после каждого хода и после покупки спецфишки;
  - переставляются **все** фишки и ячейки любых уровней **и спецфишки**; дыры остаются на месте;
  - после перемешивания нет готовых совпадений и есть хотя бы один ход. Если перестановкой
    этого не добиться — отдельные фишки 1 уровня меняют цвет, пока ход не появится
    (ячейки 2–3 уровня и спецфишки не перекрашиваются);
  - перемешивание хода не тратит.

### Совпадения: сразу объединение

Любое совпадение 1 и 2 уровня **сразу, без выбора игрока** объединяется в ячейки уровнем выше:

| Совпадение (любой формы)         | Результат                      |
| -------------------------------- | ------------------------------ |
| 3–4 клетки (в т. ч. квадрат 2×2) | **1 ячейка** следующего уровня |
| 5 и больше клеток (линия, L/T)   | **2 ячейки** следующего уровня |

- 1 уровень → 2 уровень, 2 уровень → 3 уровень. 3 уровень дальше не объединяется.
- **Совпадение 3 уровня** даёт очки и **спецфишку** (для мотивации собирать высокие уровни):

  | Совпадение 3 уровня | Спецфишка       |
  | ------------------- | --------------- |
  | 3 ячейки            | **Мега-бомба**  |
  | 4 ячейки            | **Манипулятор** |
  | 5 и больше          | **Радуга**      |

  Спецфишка появляется там же, где появилась бы объединённая ячейка (см. ниже).

- Все клетки группы приносят очки (см. «Очки»).
- Совпадения 1 и 2 уровня спецфишек не дают. Бомба и ракета появляются только из
  **покупки за очки**; манипулятор и радуга — из покупки и из совпадений 3 уровня;
  мега-бомба — только из совпадений 3 уровня.

**Все спецфишки бесцветные** (ракета, бомба, радуга, манипулятор, мега-бомба) и в совпадениях
не участвуют — они разрывают линии, как пустые клетки.

### Где появляется объединённая ячейка или спецфишка

- На ходе игрока — **в клетке, куда игрок передвинул фишку** (если она входит в группу;
  иначе — во второй клетке обмена).
- В каскаде и после активации тапом — в середине линии, у L/T — на пересечении,
  у квадрата 2×2 — в левой верхней клетке.
- Вторая объединённая ячейка (когда их 2) — в соседней клетке той же группы
  (порядок проверки: справа, слева, снизу, сверху).

### Активация спецфишек

- **Ракета, бомба** — игрок меняет их с **любой соседней клеткой** (обычной фишкой или
  манипулятором; совпадение не нужно, **тратит ход**) — и они срабатывают **в клетке, куда
  переехали**. Обмен с другой спецфишкой — комбо (см. ниже). Также срабатывают, когда задеты взрывом.
- **Мега-бомба** — как ракета и бомба: игрок меняет её с **любой соседней клеткой**
  (совпадение не нужно, **тратит ход**), и она взрывается 5×5 **в клетке, куда переехала**.
  Также срабатывает по тапу на месте (**тратит ход**) или когда задета другим взрывом.
- **Радуга** — тап по ней → тап по любой фишке на поле: убираются все фишки этого цвета
  (любого уровня). **Тратит ход.** Если радугу задело взрывом — она сама убирает
  **самый частый цвет** на поле (при равенстве — цвет с меньшим индексом).
- **Манипулятор** — тап по нему → выбор двух любых клеток → они меняются местами.
  Совпадение не требуется, **тратит ход**, после использования манипулятор исчезает.
  Если манипулятор задело взрывом — он просто исчезает.
  Манипулятор можно **сдвинуть** на соседнюю фишку обычным обменом, если это даёт совпадение:
  он просто переезжает и остаётся на поле (ход тратится). Без совпадения обмен откатывается.
- Радугу **нельзя менять с обычной фишкой**; её можно поменять с другой спецфишкой (комбо).
  Манипулятор в комбо не участвует.
- Задетые спецфишки срабатывают цепочкой.

### Комбо при обмене двух спецфишек

| Обмен                   | Результат                                                                               |
| ----------------------- | --------------------------------------------------------------------------------------- |
| Ракета + ракета         | Крест: строка + столбец                                                                 |
| Ракета + бомба          | 3 строки + 3 столбца                                                                    |
| Бомба + бомба           | Взрыв 5×5                                                                               |
| Радуга + ракета/бомба   | Фишки **самого частого цвета** превращаются в ракеты/бомбы и срабатывают                |
| Радуга + радуга         | Очистка всего поля                                                                      |
| Мега-бомба + ракета     | 5 строк + 5 столбцов                                                                    |
| Мега-бомба + бомба      | Взрыв 7×7                                                                               |
| Мега-бомба + мега-бомба | Очистка всего поля                                                                      |
| Мега-бомба + радуга     | Игрок тапом выбирает цвет; все фишки этого цвета превращаются в бомбы 3×3 и срабатывают |

- Центр комбо — клетка, куда игрок передвинул фишку.
- Превращаются **только фишки 1 уровня** этого цвета; ячейки 2–3 уровня не трогаются.
  Самый частый цвет считается по всем фишкам на поле (при равенстве — с меньшим индексом).
  Направление новых ракет — случайное.

### Уровни ячеек

- **Уровень 1** — обычные фишки, **2** и **3** — объединённые ячейки (см. «Совпадения: сразу
  объединение»). Максимальный уровень — **3**.
- Объединённые ячейки совпадают **только с ячейками того же цвета и того же уровня**.
- Фишки — цветные фигуры (5 цветов: красный, зелёный, синий, фиолетовый, оранжевый),
  уровень виден по форме: **1 уровень — круг, 2 — треугольник, 3 — пятиконечная звезда**.

### Очки

| Совпадение    | Очки за каждую клетку группы |
| ------------- | ---------------------------- |
| 1 уровень     | 10                           |
| 2 уровень     | ×5 — 50                      |
| 3 уровень, 3  | ×15 — 150                    |
| 3 уровень, 4  | ×20 — 200                    |
| 3 уровень, 5+ | ×25 — 250                    |

- Клетки, ушедшие в объединение, очки **дают**.
- Бонуса за каскады **нет**: каскадные совпадения считаются как обычные.
- Клетка, уничтоженная спецфишкой (не в совпадении): 1 уровень — 10, 2 уровень — ×5,
  3 уровень — ×15. Сами спецфишки очков не дают.

### Выбор игрока

- Сейчас совпадения выбора не требуют. Механизм выбора (шаг `choice`, диалог) оставлен в коде:
  если выбор вернётся, он показывается и на ходе игрока, и во время каскадов (каскад на паузе),
  а другие действия на поле в это время заблокированы.

### Счётчик ходов

- Рядом с очками — «Ходы: N»: сколько ходов сделано в партии. Считается всё, что тратит ход
  (обмен, срабатывание спецфишки обменом или тапом, манипулятор). Покупка спецфишки
  и перемешивание поля ходами не считаются.

### Покупка спецфишек за очки

- Над полем, под счётом, — кнопки спецфишек с ценой в очках:

  | Цена | Спецфишка                        |
  | ---- | -------------------------------- |
  | 150  | Бомба (взрыв 3×3)                |
  | 300  | Ракета (направление — случайное) |
  | 500  | Манипулятор                      |
  | 750  | Радуга                           |

- Кнопка, на которую хватает очков, подсвечена и пульсирует.
- Тап по доступной кнопке: **цена списывается со счёта** (было 600, купил бомбу — стало 450),
  спецфишка встаёт на место **случайной фишки 1 уровня** (фишка исчезает без очков).
  **Хода не тратит.** Покупать можно сколько угодно раз, пока хватает очков.
- Купить нельзя во время хода, выбора игрока и режимов радуги/манипулятора.
- Покупку **отменить нельзя**.

### Шаг назад / шаг вперёд (временно, только для тестов)

- **В окончательной версии этих кнопок не будет** — это инструмент для ручной проверки.
- Две кнопки-стрелки над полем: отменить последний ход и вернуть отменённый.
- Число шагов не ограничено. Новый ход после шага назад стирает отменённые ходы.
- Вместе с полем и очками откатывается и ГСЧ: повтор того же хода даёт
  тот же результат.
- Покупка спецфишки очищает историю: дальше этого момента шаг назад не идёт.
- Во время анимаций и выбора игрока кнопки не работают.

### Цели уровней

- Создать N объединённых ячеек (указанного уровня и/или цвета).
- Набрать N очков.
- Разрушить лёд/плитки под фишками.
- Препятствия: камни, цепи (закованные фишки), дыры в поле.

Уровень может сочетать несколько целей.

### Звёзды

- Пройти уровень = выполнить основные цели.
- Звёзды (до 3) даются за **дополнительные задачи** уровня, которые описываются в JSON уровня
  (например «создай 2 ячейки 3 уровня», «закончи с 5+ ходами в запасе»).

## Первая версия включает

- Все правила выше.
- **Карта уровней** и **1–3 звезды** за прохождение.
- **Подсказка хода** при бездействии.
- **Звуки и музыка.**
- **Редактор уровней** (доступен в dev-режиме, сохраняет уровень в JSON).

## Данные

- **Уровни** — JSON-файлы в `src/levels/`, проверяются по схеме/типу при загрузке.
- **Прогресс игрока** (пройденные уровни, звёзды, настройки) — `localStorage`.
  Доступ к нему обёрнут в try/catch: игра должна работать, даже если хранилище недоступно.

## Структура

```
src/
  core/        # чистая игровая логика: без Phaser и DOM
    board.ts       # модель поля: клетки, позиции
    generate.ts    # стартовое поле без совпадений и с хотя бы одним ходом
    match.ts       # поиск совпадений и их форм (линия, L/T, 2×2)
    specials.ts    # зоны поражения спецфишек, цепные реакции, комбо, очки за попадание
    gravity.ts     # падение и заполнение
    resolve.ts     # разбор хода (генератор шагов): эффект хода → совпадения → выбор игрока →
                   # удаление → создание спецфишек/объединение → падение → заполнение → …
    moves.ts       # проверка обмена, поиск ходов, подсказки, перемешивание
    goals.ts       # цели уровня и их прогресс
    game.ts        # состояние партии: очки, ходы, ожидание выбора, конец уровня
    bonus.ts       # покупка спецфишек за очки: цены, списание, выдача спецфишки
    history.ts     # история снимков для шага назад / вперёд (временно, для тестов)
    rng.ts         # детерминированный ГСЧ с seed
    config.ts      # все игровые константы
  scenes/      # сцены Phaser: Boot, Map, Game, Editor, Result
  view/        # отображение поля, анимации, маркеры уровней
  ui/          # HUD, диалог выбора, меню
  audio/       # звуки и музыка
  levels/      # JSON уровней
  storage/     # прогресс в localStorage
  main.ts
tests/         # зеркалят src/core; tests/helpers/ — parseBoard и прочие утилиты
scripts/       # служебные скрипты (simulate.ts — симуляция партий для баланса)
public/assets/
```

## Архитектурные правила

1. **`core/` не зависит от Phaser, DOM, таймеров.** Вся логика тестируется без браузера.
2. **Логика возвращает шаги, вид их анимирует.** `resolveMove` — генератор, который отдаёт шаги
   `swap`, `clear`, `transform`, `drop`, `choice`. На шаге `choice` он останавливается, пока сцена
   не передаст выбор игрока через `next(option)`. В тестах ход прогоняется через `runMove`.
3. **Детерминизм:** вся случайность — через `core/rng.ts` с seed, без `Math.random()` в `core/`.
4. Ввод блокируется во время анимаций и ожидания выбора.
5. Координаты `row` (сверху вниз) и `col`; поле — `cells[row][col]`, пустая клетка — `null`,
   дыра в поле — отдельный тип клетки.
6. Все числа (множители, размеры взрывов, длительности анимаций) — в `core/config.ts`.

## Тесты

- Каждое правило игры покрыто тестом в `tests/core/`, особенно: формы совпадений, объединение
  по уровням, выбор игрока в каскадах, спецфишки, цели уровней.
- Поля в тестах задаются строковой нотацией (цвет + уровень), например:
  ```ts
  const board = parseBoard(`
    R1 R1 G1
    B2 B2 B2
    G1 R3 G1
  `);
  ```
  Спецфишки: `-` / `|` — ракета по строке / столбцу, `*` — бомба, `@` — радуга,
  `M` — манипулятор, `X` — мега-бомба; `.` — пусто, `#` — дыра.
- Для случайных сценариев — фиксированный seed.
- Для ручной проверки в браузере: `?seed=N` в адресе даёт одинаковое поле, а в dev-режиме
  из консоли доступно `window.gameScene.debugSetBoard(board)`.
- Баг в логике → сначала падающий тест, потом исправление.

## Правила для агента

- **Не меняй правила игры сам.** Любое изменение механики — только после согласования
  с пользователем. Если правило не описано или неоднозначно — спроси, а не додумывай.
- **Коммить самостоятельно** после каждого завершённого шага, когда проходят тесты, линтер
  и проверка типов. Сообщение коммита — кратко, по-русски, о сути изменения. Не пушь без просьбы.
- Работай небольшими шагами; перед крупным изменением кратко опиши план.
- Если меняешь структуру, команды или правила — обнови этот файл.
- Визуальную часть проверяй через `npm run dev` в браузере, в том числе в мобильном размере экрана.
